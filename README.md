# HOTEL-BOOKING-CANCELLATION-CLASSIFICATION
A Data Mining project that predicts whether a hotel booking will be cancelled using Machine Learning techniques.

## Objective

To identify patterns in hotel booking data, predict booking cancellations, and determine the factors that influence cancellation behaviour.

## Dataset

* 119,390 hotel bookings
* 32 variables
* Data from 2015–2017
* City Hotel and Resort Hotel
* Target variable: `is_cancelled`

## Models Used

* Naive Bayes
* Random Forest

## Key Findings

* Random Forest performed better than Naive Bayes.
* Random Forest achieved an AUC of 90% and accuracy of 85% for the Resort Hotel.
* **Lead time, ADR, and deposit type** were the most important predictors.
* City Hotels had a higher cancellation rate than Resort Hotels.

## Tools

* Orange Data Mining
* Machine Learning
* Data Visualization
* Classification
